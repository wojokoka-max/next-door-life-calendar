# next-door-callendar
Kalendarz całego życia — nie tylko spotkań. Wydarzenia, zadania, przypomnienia i oś czasu, która z każdym rokiem staje się cenniejsza.  Aplikacja osobista. Bez kont, bez logowania, bez serwera i bez bazy w chmurze. Wszystko zapisuje się w pamięci przeglądarki na tym urządzeniu, na którym jest używane. Dane nigdzie nie wychodzą.
